# Practice Questions — Dashboard Design

Use `data/retail_orders_synthetic.csv` from the repository root. Answer each question with code and a one-sentence interpretation.

1. Load the CSV and show its dimensions and column types.
2. Count orders by status and explain the effect of filtering.
3. Create gross sales, net sales, and profit fields.
4. Calculate completed-order revenue and order count.
5. Rank regions by completed-order revenue.
6. Rank product categories by profit.
7. Calculate average order value for each channel.
8. Plot a labeled bar chart of category revenue.
9. Plot monthly completed-order revenue as a line chart.
10. Plot the distribution of completed-order net sales.
11. Compare net sales distributions by category with a boxplot.
12. Build a region-by-category revenue pivot table.
13. Create a heatmap of that pivot table.
14. Calculate margin for each region; handle zero revenue.
15. Make one interactive Plotly chart with informative hover labels.
16. Write three business observations and one limitation.
